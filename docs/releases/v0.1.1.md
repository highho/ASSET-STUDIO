# ASSET STUDIO 0.1.1 · Windows 图标修复版

ASSET STUDIO 0.1.0 的 Windows 桌面版还在用 Electron 默认图标。0.1.1 把应用图标、安装器图标、快捷方式图标和窗口图标统一换成自制的 Win9x 风格图标。

## 这次改了什么

- **应用图标**：银灰 Win9x 窗口边框、深蓝渐变标题条、黑底 3D 视口与网格，中央是一枚橙色等轴 3D 方块，方块正面带小资产标签。
- **Windows exe**：`ASSET STUDIO.exe` 已嵌入多尺寸 ICO，资源管理器、任务栏、Alt-Tab 不再显示 Electron 默认图标。
- **NSIS 安装器**：安装器自身和安装向导头部都使用同一图标；安装后生成的桌面快捷方式、开始菜单快捷方式同步使用新图标。
- **Electron 窗口**：主窗口与启动 splash 都显式设置 `icon`，窗口左上角也不再是默认图标。
- **Web favicon**：浏览器标签页改用 `/favicon.ico`，与桌面端同一套图标。

## 安装包

- 文件：`ASSET-STUDIO-0.1.1-Setup.exe`
- 大小：130,967,818 bytes / 124.9 MB
- SHA256：`B1A93AAA6985A8E96BEA233D5A02D220F169D57833CC5B2DAF5442C54EF4C0F2`
- 平台：Windows x64，NSIS 安装器，未签名

安装包未做代码签名，Windows SmartScreen 仍可能提示“未知发布者”；这是未签名应用的限制，不是安装包损坏。校验 SHA256 后再运行。

## 安装

1. 下载 `ASSET-STUDIO-0.1.1-Setup.exe` 和对应的 `.sha256`。
2. 校验 SHA256。
3. 双击安装，按向导选择安装目录。
4. 首次启动会进入三步引导；安装版首次启动是空资产库，仓库和安装包都不含资产数据。

## 数据目录

- 资产、缩略图、版本、AI 配置：`%APPDATA%\asset-studio\data`
- 服务日志：`%APPDATA%\asset-studio\server.log`
- 可用 `ASSET_STUDIO_DATA` 覆盖数据目录
- 桌面版端口优先 `17890`，被占用时自动回退空闲端口

## 已知限制

- 安装包未签名。
- 图标按 16 / 24 / 32 / 48 / 64 / 128 / 256 七个尺寸打包；16px 下细节会糊，32px 及以上可以辨认窗口与橙色方块。
- 0.1.1 只处理图标与版本号，功能与 0.1.0 一致。

## 从源码构建

```powershell
npm install
npm run desktop:dist
```

产物在 `release\ASSET-STUDIO-0.1.1-Setup.exe`。
